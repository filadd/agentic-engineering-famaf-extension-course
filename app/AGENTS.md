# kurasu

A classroom companion web for the Agentic Engineering FaMAF extension course. It shares each session's content and other course material with students.

## Docs

- **Docs**: `docs/`. Read its `README.md` before adding, editing, renaming or moving anything under it.
- **Folders**:
  - `architecture/` — the shape of the system and how each part works.
  - `prototipos/` — no notes, only the HTML prototypes of the screens that the notes link to.

### When adding something

- A change to how a part of the app works → a note in `docs/architecture/`

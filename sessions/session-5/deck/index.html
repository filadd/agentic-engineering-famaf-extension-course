Coding agent: un archivo, una línea por entrada.
Si muere a mitad de un turno, mirás qué quedó y le decís que siga.

pi-durable: cada efecto es un sándwich

1commitear la intención"voy a correr bash"
2hacer el efectocorre la tool
3commitear el resultado"salió esto"
💥 Si se cae entre 1 y 3: la tool se vuelve a correr solo si declara replay: "safe"; si no, el modelo recibe un resultado "interrupted" con lo que había.
🪆 Las tareas se anidan. Una tarea puede ser dueña de tareas hijas, con política failFast, allSettled o any. Tareas y conversaciones forman un solo árbol de pertenencia, y un abort corre de abajo hacia arriba. Ej.: la llamada al modelo espera las tareas de tools de su ronda (allSettled).

Instrucciones vagas vs. usables

La especificidad sirve cuando le saca una decisión que el agente tendría que tomar.

vagaqué faltamás usable
"Corré los tests."¿Qué tests, dónde y cuándo?Desde services/api, corré el archivo de pytest afectado mientras iterás. Corré pytest tests/ antes de terminar un cambio en la API.
"No edites el código generado."¿Qué código es generado?No edites packages/client/generated/. Cambiá schemas/openapi.yaml y corré pnpm generate:client.
"Seguí los patrones existentes."¿Cuál es la implementación de referencia?Los handlers HTTP nuevos siguen a services/api/routes/users.py, incluida la validación y el manejo de errores.
"Respetá la arquitectura."¿Qué límite hay que preservar?packages/core no puede importar de packages/ui. El código compartido va en packages/core.
"Usá el proceso de build estándar."¿Qué es lo estándar acá?Corré make build desde la raíz del repo. No uses go build: el wrapper agrega metadata que el build necesita.

Host, cliente y servidor

un cliente por servidor el servidor puede vivir en tu máquina o en internet

Lo que puede ofrecer un servidor

🔧

tools

funciones que se ejecutan: consultar una base, crear un issue

las elige el modelotools/list · tools/call
📚

resources

datos para leer: un archivo, el schema de la base

los elige la aplicaciónresources/list · resources/read
💬

prompts

plantillas reutilizables: "revisá este PR"

los elige el usuarioprompts/list · prompts/get
🙋
y al revés, el servidor le puede pedir al cliente: elicitation"¿confirmás que borro estos 40 registros?" — le pregunta al usuario a través del host

  • Playwright y Chrome DevTools MCP: 13.7k y 18k tokens, antes de empezar
  • la alternativa: cuatro scripts y un README de ~225 tokens
  • la salida de un CLI se encadena; la de MCP pasa por el contexto
MCP servers also aren't composable.
→
sep 2026 · Earendil, el equipo de Pi

“You Said No MCP!” ↗

  • MCP entra al núcleo de Pi 1.0
  • las tools no se declaran: se llaman desde codemode, o se cargan con tool_search
  • codemode corre del lado del harness, no en el sandbox de las tools
The biggest issue with MCP continues to be that it's hard to compose.

La crítica no se retiró: se convirtió en diseño.
el costo → descubrimiento progresivo · la composición → code mode
